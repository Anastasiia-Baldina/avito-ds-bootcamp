# Определение автоматизированного трафика

## Задача

Нужно определить, относится ли трафик пользователя к автоматизированному сбору данных. Для каждой `cookie_id` требуется получить непрерывный `score` от 0 до 1. Чем выше значение, тем больше модель уверена, что трафик относится к автоматизированному.

Для построения признаков используются события пользователя только внутри заданного окна наблюдения. Основная метрика качества равна максимальному Precision при Recall не ниже 0.70.

## Подход

Я использовала признаки по действиям пользователя внутри окна наблюдения. Учитывала количество и типы событий, интервалы между действиями, число уникальных объявлений, категорий и локаций, поисковую активность, платформу, user agent и движение курсора. Качество проверяла по времени, обучая модель на более ранних датах и проверяя на следующих периодах. Основной метрикой был максимальный Precision при Recall не ниже 0.70. Дополнительно проверила качество на периоде длиной семь дней. Сравнила Random Forest и CatBoost. Лучший результат показал CatBoost глубины 7 с 107 признаками. Среднее значение основной метрики на пяти временных проверках получилось около 0.742, а на семидневной проверке около 0.719.
